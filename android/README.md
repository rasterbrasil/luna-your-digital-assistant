# Luna Android Agent — Fase 5

Companion app Android para a Luna observar e controlar o telefone através do `AccessibilityService`.

## Primeiro teste no celular
1. Instale o app.
2. Abra **Ativar acessibilidade da Luna**.
3. Ative `Luna Accessibility`.
4. Volte ao app e use **Teste: observar tela**, **Tela inicial** e **Voltar**.

A API remota `LUNA-ANDROID/1` será adicionada na próxima etapa da mesma fase. O primeiro objetivo é validar no aparelho real que a camada de percepção/ação Android funciona antes de conectar o cérebro web.
